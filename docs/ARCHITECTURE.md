# البنية التقنية لموسوعة أثَر

## 1. الهدف

بناء موسوعة لغوية متعددة اللغات لتوثيق أصول الكلمات ورحلتها التاريخية بين اللغات، مع المعاني والشواهد والادعاءات والمراجع العلمية.

## 2. مكونات النظام

### الواجهة الأمامية
- الاسم التقني الحالي: athar-word-app
- التقنية: HTML وCSS وJavaScript.
- المسؤولية: عرض الموسوعة والبحث والتصفح واختيار لغة المحتوى.
- لا تتصل بقاعدة البيانات مباشرة.

### الخلفية وواجهة API
- الاسم: athar-lab
- التقنية: Cloudflare Worker.
- المسؤولية: استقبال طلبات الواجهة، والتحقق منها، وجلب البيانات من قاعدة البيانات وإعادتها بصورة منظمة.

### قاعدة البيانات
- الاسم: athar-db
- التقنية: Cloudflare D1.
- المسؤولية: تخزين الكلمات والمعاني والترجمات والمراحل التأثيلية والادعاءات والمراجع والمراجعات.

## 3. طريقة الاتصال المستهدفة

المستخدم
   ↓
واجهة أثَر (athar-word-app)
   ↓ HTTPS API
الخلفية (athar-lab)
   ↓ D1 Binding: DB
قاعدة البيانات (athar-db)

يجب ضبط CORS والتحقق من الطلبات وحماية وظائف الإدارة قبل اعتماد الاتصال للإنتاج.

## 4. اللغات

اللغات المستهدفة:
- العربية
- الإنجليزية
- الفرنسية
- الروسية

يجب أن تتضمن كل لغة المحتوى العلمي المناسب لها، وليس ترجمة عناصر الواجهة فقط.

## 5. المعايير العلمية

- التمييز بين الحقيقة والفرضية والرواية الشائعة.
- توضيح قوة الأدلة ودرجة الثقة.
- ربط الادعاءات بالمراجع والشواهد.
- إظهار المراجع العربية الموثوقة متى توفرت.
- عدم اختلاق المصادر أو مسارات انتقال الكلمات.
- التصريح بالمسائل التي لا تزال محل خلاف.

## 6. قواعد حماية المشروع

- عدم حذف النسخ القديمة أو الاحتياطية.
- عدم تعديل قاعدة البيانات أو حذف بياناتها دون مراجعة ونسخة احتياطية.
- عدم نشر تغييرات إلى الموقع الحي دون مراجعة وموافقة.
- عدم تخزين كلمات المرور أو مفاتيح API في المستودع.
- إجراء التطوير التجريبي على الفرع athar-development.
- الحفاظ على الفرع main مستقرًا.

## 7. الوضع الحالي

هذا المستودع يحتوي على نسخة أولية قديمة من الواجهة.

الواجهة الحالية المنشورة ذات 94 مدخلًا موجودة بصورة منفصلة على athar-word-app.

الخلفية athar-lab وقاعدة البيانات athar-db موجودتان بصورة منفصلة عن هذا المستودع.

لم يكتمل بعد ربط الواجهة الحالية بواجهة API لعرض بيانات قاعدة البيانات.

## 8. مراحل التطوير القادمة

1. توثيق البنية التقنية.
2. جرد ملفات الواجهة الحالية وحفظ نسخة آمنة منها.
3. مراجعة API في athar-lab.
4. استكمال واجهات جلب تفاصيل الكلمات والمراجع والمراحل والادعاءات.
5. ربط الواجهة بواجهة API.
6. اختبار البحث واللغات والمحتوى.
7. مراجعة الأمان والأداء قبل النشر.
