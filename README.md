# أثَر | ATHAR Encyclopedia

موسوعة لغوية متعددة اللغات تبحث في أصول الكلمات ورحلتها التاريخية بين اللغات.

## رؤية المشروع

لكل كلمة حكاية، ولكل حكاية أثر.

يهدف المشروع إلى تقديم محتوى علمي موثق حول:
- أصول الكلمات واشتقاقاتها.
- مراحل انتقال الكلمات بين اللغات.
- المعاني والتطورات التاريخية والثقافية.
- الادعاءات والروايات الشائعة حول أصول الكلمات.
- المراجع والشواهد ودرجات الثقة العلمية.

## اللغات المستهدفة

- العربية
- الإنجليزية
- الفرنسية
- الروسية

يجب أن يكون المحتوى العلمي متاحًا باللغة المختارة، وليس مجرد ترجمة لعناوين الواجهة.

## البنية التقنية المستهدفة

- **Frontend:** واجهة ويب باستخدام HTML وCSS وJavaScript.
- **Backend:** Cloudflare Worker باسم `athar-lab`.
- **Database:** قاعدة بيانات Cloudflare D1 باسم `athar-db`.
- **API:** واجهة آمنة تربط الموقع بقاعدة البيانات.

## الوضع الحالي

هذا المستودع يحتوي حاليًا على نسخة أولية قديمة من واجهة أثَر، ويُستخدم لتنظيم التطوير وحفظ التعديلات.

النسخة الحالية المنشورة ذات 94 مدخلًا موجودة بصورة منفصلة على `athar-word-app`.

لن تُستبدل النسخة المنشورة أو تُنقل ملفاتها قبل مراجعتها وتوحيدها مع هذا المستودع بطريقة آمنة.

## المعايير العلمية والتحريرية

1. الاعتماد على مراجع موثوقة وقابلة للتحقق.
2. إظهار المراجع العربية المناسبة إلى جانب الأجنبية متى توفرت.
3. التمييز بين الحقيقة المثبتة والفرضية والرواية الشائعة.
4. عدم تقديم الفرضيات أو الروايات غير المحسومة باعتبارها حقائق.
5. توضيح مواضع الخلاف وعدم اليقين في تاريخ الكلمات.
6. عدم اختلاق الشواهد أو المراجع.

## قواعد التطوير

- فرع `main` محفوظ ولا تُجرى عليه التعديلات التجريبية مباشرة.
- يجري التطوير في فرع `athar-development`.
- عدم حذف البيانات أو الجداول أو النسخ الاحتياطية دون مراجعة.
- عدم وضع مفاتيح API أو كلمات المرور أو الأسرار داخل المستودع.
- عدم نشر أي تغيير إلى النسخة الحية دون مراجعة وموافقة صريحة.
- الاحتفاظ بتاريخ التعديلات وإمكانية الرجوع إلى النسخ السابقة.

## الهدف النهائي

بناء موسوعة لغوية موثوقة، متعددة اللغات، قابلة للتوسع، تجمع بين البحث التأثيلي والتحليل التاريخي والتوثيق العلمي.
